## Настроить на компьютере изолированное окружение: CPython 3.12.3, NumPy 2.1.0 и OpenCV contrib headless 4.10.0.84.

### 📦 Шаг 1: Проверьте Python 3.12.3

Сначала убедитесь, что у вас установлен именно Python 3.12.3. Откройте терминал (командную строку или PowerShell) и выполните:

```bash
python --version
```

Или, если в вашей системе `python` не ассоциирован с Python 3.12:

```bash
python3.12 --version
```

Если версия отличается, скачайте и установите нужную с [python.org](https://www.python.org/downloads/). При установке на Windows обязательно отметьте галочку **«Add python.exe to PATH»**.

### 📁 Шаг 2: Создайте папку проекта и изолированное окружение

Создайте папку, где будет жить ваш проект, и перейдите в неё:

```bash
mkdir src
cd src
```

Теперь создайте виртуальное окружение. Эта команда создаст локальную папку `.venv` с копией Python и всеми будущими библиотеками:

```bash
python -m venv .venv
```

Если команда `python` не сработала, используйте `python3.12 -m venv .venv`.

### ⚡ Шаг 3: Активируйте окружение

Это ключевой момент, который делает окружение изолированным. После активации все команды `pip` будут ставить пакеты только внутрь `.venv`.

```bash
.venv\Scripts\activate
```

После активации в начале строки терминала появится префикс `(.venv)`. Это значит, что всё готово.

### 🛠️ Шаг 4: Обновите инструменты установки

Перед установкой библиотек стоит обновить `pip`, чтобы он корректно находил предварительно собранные пакеты (wheels) для Python 3.12 и не пытался компилировать их из исходников:

```bash
python -m pip install --upgrade pip setuptools wheel
```

### 📥 Шаг 5: Установите точные версии NumPy и OpenCV

Теперь установите пакеты с указанием конкретных версий. Используйте `python -m pip` вместо просто `pip`, чтобы гарантированно использовать Python из активированного окружения.

```bash
python -m pip install numpy==2.1.0 opencv-contrib-python-headless==4.10.0.84
```

**Важный нюанс по OpenCV:** Вы выбрали правильный пакет (`opencv-contrib-python-headless`), так как он включает дополнительные модули (contrib) и не требует графического интерфейса (headless), что идеально для серверов или CI. **Никогда не устанавливайте одновременно разные варианты OpenCV** (например, `opencv-python` и `opencv-contrib-python`), так как они конфликтуют и перезаписывают файлы `cv2`.

### ✅ Шаг 6: Проверьте изоляцию и работу

Чтобы убедиться, что всё установилось в изолированное окружение и работает, выполните несколько команд прямо в том же терминале.

Сначала проверьте, что Python видит именно установленные версии:

```bash
python -c "import numpy; print('NumPy:', numpy.__version__)"
python -c "import cv2; print('OpenCV:', cv2.__version__)"
```

Ожидаемый вывод:

```
NumPy: 2.1.0
OpenCV: 4.10.0
```

Теперь проверьте, куда именно установились пакеты. Путь должен указывать внутрь папки `.venv`:

```bash
python -c "import numpy; print(numpy.__file__)"
```

Вы должны увидеть путь, содержащий `src/.venv/...`, а не системную папку.

### 💡 Полезные команды на будущее

- **Выход из окружения:** Когда закончите работу, просто введите `deactivate` в терминале. Окружение отключится, и вы вернётесь к системному Python.
- **Повторный вход:** Чтобы снова начать работу, откройте терминал, перейдите в папку `src` и снова активируйте окружение командой из Шага 3.
- **Файл зависимостей:** Чтобы зафиксировать эти версии для будущих установок, можно создать файл `requirements.txt` с содержимым:
```
numpy==2.1.0
opencv-contrib-python-headless==4.10.0.84
```

Теперь, если вы развернёте проект на другой машине, достаточно будет активировать окружение и выполнить:
```bash
python -m pip install -r requirements.txt
```

### Можно автоматически сгенерировать файл requirements.txt.

Убедитесь, что окружение активировано (`(.venv)` в начале строки), затем выполните:

```bash
python -m pip freeze > requirements.txt
```

Команда создаст файл `requirements.txt` в текущей папке.
